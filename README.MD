# Note-Jeppe

My public notebook of statistical and machine learning examples: explanations, visualizations and code snippets, built as a Quarto book with Python. I write these mostly for fun, so expect a mix of polished tutorials and rough experiments.

## Notes

- Chapters are self-contained and can be read in any order.
- Computed results are cached with Quarto's freeze feature in `_freeze/`.
- Python packages are listed in `requirements.txt`.
